Getting Started with EODH

On the day, all teams work in the Earth Observation Data Hub (EODH). Please complete Steps 1–2 before the EODH workspace introduction on Wednesday 2 December, so that the session can focus on data and notebooks rather than logins.

Tip

In short
Create an EODH account with your GitHub, Google (Gmail) or Microsoft login → tell us the email you used → we add you to your team’s workspace → open a notebook.

Access levels

The EODH has three access levels:

Access level What it allows Do you need it?
Open access Browse the site and docs, search the catalogue, view and download open imagery. No sign-in. Useful for exploring beforehand
User account Join and work in shared workspaces you’ve been invited to. You can’t create workspaces. Yes — every technical participant
User account + billing account Create and manage your own workspaces, plus commercial data, hosted notebooks, storage and workflows. No — the organisers handle workspaces

You only need a user account. The organisers will set up team workspaces and add you to yours.

Step 1 — Create your account

  1. Go to eodatahub.org.uk and click Sign in (top right).
  2. Choose an identity provider: GitHub, Google (Gmail) or Microsoft. You need one of these to create an account.
  3. Sign in with that provider’s credentials.
  4. On your first login, fill in the account information fields.

Notes for each provider:

  • GitHub: on first login you’ll be asked to authorise EO-DataHub.
  • Google: on first login, review the identity information requested and select Continue.
  • Microsoft (e.g. a council or university account): signing in sends an access request email (“Request for access to eodh-prod received”) that expires after 24 hours. Your organisation’s Microsoft administrator has to approve the eodh-prod application once, after which anyone in your organisation can sign in.
Warning

Using a work Microsoft account?
Council and NHS IT approval can take time. If you plan to sign in with a work Microsoft account, start before 30 November, or use a personal GitHub or Gmail account instead.

Full guide: EODH — User accounts

Step 2 — Send us your account email

Once your account exists, send the email address linked to your EODH account to the organisers so we can add you to your team’s workspace.

Step 3 — Open a notebook in your workspace

When you’ve been added to a workspace (we’ll walk through this on 2 December):

  1. From the EODH homepage, open Notebooks in the navigation bar and sign in if prompted.
  2. Click Start My Server.
  3. Select your team’s workspace. This decides which storage is mounted in your notebook.
  4. Select a profile. The EO DataHub default image is recommended, as it comes with extra packages including the pyeodh client. A plain Python image is also available. The hackathon supports Python only.
  5. Click Start, wait for the server, then create a notebook from the Python 3 (ipykernel) tile.
Note

Good habits
Stop your server when you’re done via File → Hub Control Panel; logging out doesn’t stop it. Idle servers shut down after one hour, so save your work often.

Full guide: EODH — Notebook service

Step 4 — Explore before the day (optional)

  • Resource catalogue: data discovery: search and browse what’s on the Hub (no login needed).
  • Setup walkthrough, then the discovery, processing and visualisation walkthroughs.
  • Heat-relevant examples: Mapping land surface temperature across the UK and Landsat land surface temperature. These are good starting points for the What makes a hotspot? and Does green cool? challenges.
  • pyeodh, the Python client for EODH APIs.
  • Prefer desktop GIS? EODH can also be reached from QGIS and ArcGIS.

Stuck? See the EODH FAQs and cheat sheet, or bring your question to the 2 December session.
